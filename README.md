# Библиотека уроков

Личная учебная библиотека: https://getman-danil.github.io/learn/

- Каждый урок — отдельный файл в `lessons/`.
- Прогресс, закреплённые темы и напоминания о повторении хранятся только в браузере.
- Кнопка «Хочу изучить…» создаёт заявку (Issue), по которой урок делается автоматически.

Как устроен сайт и формат урока: [CLAUDE.md](CLAUDE.md).
